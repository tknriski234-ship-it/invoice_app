# Backend Learning Roadmap (Python Focus)

## 🎯 Goal

Mampu bikin backend API yang:

* Bisa dipakai (real use)
* Bisa di-deploy
* Bisa jadi portfolio / sumber income

---

## 📌 Phase 1 — Python Basic (Wajib Kuat)

**Fokus:**

* Variable, data type
* Function
* Loop & condition
* Error handling (`try-except`)
* Basic OOP (class, object)

**Target:**

* Bisa bikin logic program tanpa bingung
* Gak ngasal copy paste

---

## 📌 Phase 2 — Basic Backend (FastAPI / Flask)

**Fokus:**

* Routing (`GET`, `POST`, dll)
* Request & response
* JSON

**Latihan:**

* API sederhana:

  * `/hello`
  * `/users`
  * `/products`

**Target:**

* Paham alur request → response

---

## 📌 Phase 3 — Database (SQL WAJIB)

**Fokus:**

* SELECT
* INSERT
* UPDATE
* DELETE
* JOIN dasar

**Tools:**

* PostgreSQL / MySQL / SQLite

**Latihan:**

* Simpan data user
* Ambil data dari database

**Target:**

* Ngerti cara data disimpan & diambil

---

## 📌 Phase 4 — CRUD API

**Fokus:**

* Create
* Read
* Update
* Delete

**Project kecil:**

* Todo API
* User API

**Target:**

* Bisa bikin API yang lengkap

---

## 📌 Phase 5 — Authentication

**Fokus:**

* Login system
* JWT (token)

**Latihan:**

* Register
* Login
* Protect route

**Target:**

* API punya sistem keamanan dasar

---

## 📌 Phase 6 — ORM (Optional Next Step)

**Fokus:**

* SQLAlchemy
* Mapping table ke object

**Catatan:**

* Pelajari setelah paham SQL

---

## 📌 Phase 7 — Migration

**Fokus:**

* Alembic
* Versioning database

**Kapan dipelajari:**

* Saat project mulai kompleks

---

## 📌 Phase 8 — Deploy

**Fokus:**

* Deploy ke:

  * Railway / Render / VPS
* Environment variables

**Target:**

* API bisa diakses online

---

## 📌 Phase 9 — Project Real (WAJIB)

**Contoh:**

* Invoice API
* Todo App
* Simple Auth System

**Target:**

* 1 project jadi (bukan setengah)

---

## ⚠️ Rules Belajar

* Jangan lompat-lompat
* 1 konsep → praktek → lanjut
* Jangan nunggu sempurna

---

## 🎯 Target Realistis

* 1 minggu: basic API + SQL
* 2 minggu: CRUD + auth
* 3 minggu: 1 project jadi

---

## 🚀 Reminder

> Skill kecil + project jadi > teori banyak tapi kosong
